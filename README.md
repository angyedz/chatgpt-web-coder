## Как это работает

Ты отправляешь задачу в терминале. Harness управляет ChatGPT Web через браузер, а вызовы локальных инструментов проходят через MCP-коннектор и Secure MCP Tunnel. Результаты и ход работы отображаются в терминале.

```text
  твой проект      harness                 ChatGPT Web
  ───────────      ───────                 ───────────
  файлы        ◄── инструменты ◄── MCP ◄── запросы модели
  терминал         чат и план   ──────────► ответы и результаты
```

### Что умеет

| Работа с проектом | Работа с агентом |
| --- | --- |
| Файлы, патчи, команды и Git | Потоковый ответ, план и история действий |
| Фоновые процессы и таймеры | Сессии для каждого workspace |
| Веб-поиск через SearXNG | Контекст с настраиваемой компактацией |
| Внешние MCP-серверы | Skills и инструкции `AGENTS.md` |
| Подтверждение команд и записи файлов | Обновление и откат из терминала Windows |

## Быстрый старт

### 1. Установи на Windows

Распакуй полный архив проекта и запусти `install.cmd` или выполни из его папки:

```powershell
.\install.cmd
```

Установщик загрузит собственные Node.js, Git, зависимости, Chromium и tunnel-client. Затем открой **новый** терминал, перейди в папку проекта и запусти:

```powershell
cd 'C:\путь\к\проекту'
chatgpt-coder
```

Для Windows-установщика нужны Windows 10/11, интернет и доступ к скачиванию зависимостей. Подробности и решение проблем — в [инструкции по установке](docs/INSTALL-WINDOWS.md).

### 2. Подключи инструменты

Для работы через MCP нужны аккаунт ChatGPT с доступом к custom MCP connectors, созданный Secure MCP Tunnel и runtime API key с правами **Tunnels Read + Use**. Войди в ChatGPT в открывшемся браузере, затем в harness введи:

```text
/connect tunnel tunnel_...
/connect key <runtime-ключ>
```

Создай в ChatGPT custom MCP connector с подключением через этот туннель. Пошаговая инструкция — [настройка Windows](docs/INSTALL-WINDOWS.md#3-подключить-chatgpt-и-инструменты) и [справочник](docs/REFERENCE.md#tunnel-и-коннектор-chatgpt).

### Запуск из исходников

Нужны Node.js 22+ и npm. Установи зависимости и браузер, затем запусти приложение:

```powershell
npm ci
npm run setup
npm run dev
```

Настроить соединение можно через `/connect`. Для локальной конфигурации доступны [.env.example](.env.example) и [harness.config.example.json](harness.config.example.json). При запуске из исходников рабочей папкой будет текущий каталог.

## Команды

| Команда | Действие |
| --- | --- |
| `/help` · `/status` · `/doctor` | Помощь, состояние и диагностика |
| `/connect` · `/mcp` | Настройка туннеля и внешних MCP-серверов |
| `/sessions` · `/session new` | Сохранённые сессии и новая сессия |
| `/context 200k` · `/compact` | Размер контекста и ручная компактация |
| `/timer 5m` · `/jobs` | Таймеры и фоновые задачи |
| `/skills` · `/agents` | Доступные навыки и инструкции проекта |
| `/update` · `/update rollback` | Выбор обновления и откат на Windows |

Полный список с примерами — в [справочнике команд](docs/REFERENCE.md#команды-tui). Для веб-поиска нужен доступный SearXNG с JSON API; остальные инструменты могут работать без него.

## Обновление

В установленном harness выбери доверенный ZIP:

```text
/update
/update apply
```

После установки перезапусти агент. Для выбора файла без диалога используй `/update "C:\путь\к\update.zip"`. Откат: `/update rollback`, затем `/update apply` и перезапуск. Обновления не подписаны: отображаемый SHA-256 помогает определить файл, но не подтверждает его автора.

### Собрать файл обновления

Из полной папки исходников запусти:

```powershell
.\build-update.cmd
```

Сборщик установит зависимости во временную папку, скомпилирует приложение и Windows-лаунчер и создаст ZIP в `dist\updates`. Нужны интернет, Node.js 22+ с npm и компилятор .NET Framework 4.x. На компьютере получателя установка может загружать зависимости и браузер. Перед выпуском измени версию в `package.json` и `package-lock.json`.

## Данные и доступ

- Настройки, учётные данные, профиль браузера и сессии по умолчанию находятся в `~/.chatgpt-coder/`. Они могут содержать ключи и историю переписки.
- Файловые инструменты ограничены workspace; shell-команды выполняются с правами текущего пользователя. По умолчанию команды и записи требуют подтверждения.
- Результаты инструментов передаются в ChatGPT. Настраивай подтверждения и доступ к проектам с учётом содержимого данных.
- Автокомпактация использует приблизительную оценку токенов: точный внутренний счётчик ChatGPT Web недоступен.
- Интерфейс ChatGPT Web и доступность MCP могут меняться. Для поиска необходим SearXNG.
